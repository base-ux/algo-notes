# Связанные списки

Структура данных, в которой элементы расположены в линейном порядке.
Порядок определяется указателями (ссылками) на каждый элемент.
В псевдокоде процедур используются следующие атрибуты списка:
```
L.head: указатель на первый элемент списка
```
Каждый элемент списка имеет следующие атрибуты:
```
e.obj: указатель на объект, хранящий данные
e.next: указатель на следующий элемент
e.prev: указатель на предыдущий элемент (для двусвязного списка)
```
Если `L.head` имеет значение `NIL`, то список пуст.
Если `e.next` имеет значение `NIL`, то такой элемент является хвостовым.
Если `e.prev` (для двусвязного списка) имеет значение `NIL`, то такой элемент
является головным.
Атрибут `e.obj` либо представляет собой непосредственные данные (например,
числовое значение), либо указатель на структуру, содержащей данные.
Для сравнения на равенство значений применяется процедура `compare`,
которая возвращает нулевое значение при равенстве своих аргументов.

## Операции

- Поиск объекта (search)
- Вставка объекта (insert)
- Удаление объекта (delete)

### Поиск объекта (search)

Операция `search` одинакова для одно- и двусвязных списков:
```
search(L, x)
    Вход:
        L: список
        x: объект, содержащий искомые данные (ключ)
    Выход:
        указатель на объект с искомым ключом или NIL

    e := L.head
    while e != NIL и compare(e.obj, x) != 0
        e := e.next
    return e
```

### Вставка объекта (insert)

Для односвязного списка:
```
insert(L, x)
    Вход:
        L: список
        x: объект, добавляемый в начало списка

    Пусть e - новый элемент списка
    e.obj := x
    e.next := L.head
    L.head := e
```

Для двусвязного списка:
```
insert(L, x)
    Вход:
        L: список
        x: объект, добавляемый в начало списка

    Пусть e - новый элемент списка
    e.obj := x
    e.next := L.head
    e.prev := NIL
    if L.head != NIL
        L.head.prev := e
    L.head := e
```

### Удаление объекта (delete)

В процедуру удаления передаётся указатель на элемент списка.
Таким образом, для удаления конкретного объекта необходимо предварительно
найти содержащий его элемент с помощью процедуры `search`.

Для односвязного списка:
```
delete(L, e)
    Вход:
        L: список
        e: указатель на удаляемый элемент списка

    if L.head == e
        L.head = e.next
    else
        // поиск элемента, предшествующего удаляемому
        p := L.head
        while p != NIL и p.next != e
            p := p.next
        if p != NIL
            p.next := e.next
```

Для двусвязного списка:
```
delete(L, e)
    Вход:
        L: список
        e: указатель на удаляемый элемент списка

    if e.prev != NIL
        e.prev.next := e.next
    else
        L.head := e.next
    if e.next != NIL
        e.next.prev := e.prev
```

## Альтернативная реализация

В альтернативной реализации не используется отдельный атрибут `L.head`.
Вместо этого процедурам передаётся указатель на головной элемент списка или `NIL`,
если список пуст.
Кроме того процедуры `insert` и `delete` возвращают указатель на головной элемент
изменённого списка.

### Поиск объекта (search)

Операция `search` одинакова для одно- и двусвязных списков:
```
search(L, x)
    Вход:
        L: указатель на головной элемент списка
        x: объект, содержащий искомые данные (ключ)
    Выход:
        указатель на объект с искомым ключом или NIL

    e := L
    while e != NIL и compare(e.obj, x) != 0
        e := e.next
    if e != NIL
        return e.obj
    return NIL
```

### Вставка объекта (insert)

Для односвязного списка:
```
insert(L, x)
    Вход:
        L: указатель на головной элемент списка
        x: объект, добавляемый в начало списка
    Выход:
        указатель на новый головной элемент списка

    Пусть e - новый элемент списка
    e.obj := x
    e.next := L
    return e
```

Для двусвязного списка:
```
insert(L, x)
    Вход:
        L: указатель на головной элемент списка
        x: объект, добавляемый в начало списка
    Выход:
        указатель на новый головной элемент списка

    Пусть e - новый элемент списка
    e.obj := x
    e.next := L
    e.prev := NIL
    if L != NIL
        e.prev := L.prev
        if L.prev != NIL
            // если головной элемент указывает на подсписок,
            // то вставка сохраняет связность с "родительским" списком
            L.prev.next := e
        L.prev := e
    return e
```

### Удаление объекта (delete)

Для односвязного списка:
```
delete(L, x)
    Вход:
        L: указатель на головной элемент списка
        x: удаляемый объект
    Выход:
        указатель на новый головной элемент списка

    p := NIL
    e := L
    // поиск удаляемого элемента и его предшественника
    while e != NIL и compare(e.obj, x) != 0
        p := e
        e := e.next
    if e != NIL
        if p != NIL
            p.next := e.next
        if e == L
            return e.next
    return L
```

Для двусвязного списка:
```
delete(L, x)
    Вход:
        L: указатель на головной элемент списка
        x: удаляемый объект
    Выход:
        указатель на новый головной элемент списка

    e := L
    // поиск удаляемого элемента
    while e != NIL и compare(e.obj, x) != 0
        e := e.next
    if e != NIL
        if e.prev != NIL
            e.prev.next := e.next
        if e.next != NIL
            e.next.prev := e.prev
        if e == L
            return e.next
    return L
```
