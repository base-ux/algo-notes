# Связанные списки

Структура данных, в которой объекты расположены в линейном порядке.
Порядок определяется указателями (ссылками) на каждый объект.
В псевдокоде процедур используются следующие атрибуты списка:
```
L.head: указатель на первый объект списка
```
Каждый объект списка имеет следующие атрибуты:
```
x.key: ключ объекта
x.next: указатель на следующий объект
x.prev: указатель на предыдущий объект (для двусвязного списка)
```
Если `L.head` имеет значение `NIL`, то список пуст.
Если `x.next` имеет значение `NIL`, то такой объект является хвостовым.
Если `x.prev` (для двусвязного списка) имеет значение `NIL`, то такой объект
является головным.

## Операции

- Поиск объекта (search)
- Вставка объекта (insert)
- Удаление объекта (delete)

### Поиск объекта (search)

Операция `search` одинакова для одно- и двусвязных списков:
```
search(L, k)
    Вход:
        L: список
        k: искомый ключ
    Выход:
        указатель на объект с искомым ключом или NIL

    x := L.head
    while x != NIL и x.key != k
        x := x.next
    return x
```

### Вставка объекта (insert)

Для односвязного списка:
```
insert(L, x)
    Вход:
        L: список
        x: указатель на объект, добавляемый в начало списка

    x.next := L.head
    L.head := x
```

Для двусвязного списка:
```
insert(L, x)
    Вход:
        L: список
        x: указатель на объект, добавляемый в начало списка

    x.next := L.head
    x.prev := NIL
    if L.head != NIL
        L.head.prev := x
    L.head := x
```

### Удаление объекта (delete)

Для односвязного списка:
```
delete(L, x)
    Вход:
        L: список
        x: указатель на удаляемый объект

    if L.head == x
        L.head = x.next
    else
        // поиск объекта, предшествующего удаляемому
        p := L.head
        while p != NIL и p.next != x
            p := p.next
        if p != NIL
            p.next := x.next
```

Для двусвязного списка:
```
delete(L, x)
    Вход:
        L: список
        x: указатель на удаляемый объект

    if x.prev != NIL
        x.prev.next := x.next
    else
        L.head := x.next
    if x.next != NIL
        x.next.prev := x.prev
```
