# Стек

Структура данных, реализующая стратегию "последний вошёл - первый вышел"
(last-in, first-out - LIFO).
Реализуется на базе массивов или связных списков.
Далее показаны процедуры реализации стека на базе массива.
В псевдокоде процедур используются следующие атрибуты массива стека:
```
S.top: индекс вершины стека
S.first: начальный индекс массива стека
S.last: конечный индекс массива стека
```

## Операции

- Инициализация стека (initialize)
- Проверка на наличие элементов (empty)
- Проверка на переполнение (full)
- Вставка элемента (push)
- Извлечение элемента (pop)

### Инициализация стека (initialize)

```
initialize(S, p, r)
    Вход:
        S: массив стека
        p: начальный индекс подмассива S[p..r]
        r: конечный индекс подмассива S[p..r]

    if p > r
        error "Ошибка инициализации"
    S.first := p
    S.last := r
    S.top := S.first - 1
```

### Проверка на наличие элементов (empty)

```
empty(S)
    Вход:
        S: массив стека
    Выход:
        TRUE: если стек не содержит элементов
        FALSE: в противном случае

    if S.top < S.first
        return TRUE
    else
        return FALSE
```

### Проверка на переполнение (full)

```
full(S)
    Вход:
        S: массив стека
    Выход:
        TRUE: если стек переполнен
        FALSE: в противном случае

    if S.top == S.last
        return TRUE
    else
        return FALSE
```

### Вставка элемента (push)

```
push(S, x)
    Вход:
        S: массив стека
        x: добавляемый элемент

    if full(S)
        error "overflow: переполнение стека"
    S.top := S.top + 1
    S[S.top] := x
```

### Извлечение элемента (pop)

```
pop(S)
    Вход:
        S: массив стека
    Выход:
        извлекаемый элемент

    if empty(S)
        error "underflow: опустошение стека"
    S.top := S.top - 1
    return S[S.top + 1]
```
