# Основные понятия

## Переменные

**Переменная** - именованная сущность, обозначающая какое-либо значение.
Может иметь числовой, символьный, строковый, логический **тип**,
а также тип указателя (ссылочный тип).
Присваивание переменной обозначается оператором `:=`, например, `x := 0`.

## Константы

Используются следующие **константы**:

- `TRUE` (логический тип) - логическое значение "истина"
- `FALSE` (логический тип) - логическое значение "ложь"
- `NIL` - специальное обозначение отсутствия значения, либо "нулевого" указателя

## Структуры

**Структуры** имеют **атрибуты** или **поля**.
Имя атрибута отделяется от имени переменной точкой, например, `x.key`.

## Массивы

Структура, представляющая собой индексированный набор однотипных переменных (элементов).
**Индекс** записывается в квадратных скобках после имени массива, например, `A[7]`.
Массив имеет следующие атрибуты:

- `A.first` - первый индекс массива (например, 0 при индексации с нуля)
- `A.length` - размер массива, т.е. количество элементов, содержащихся в нём
- последний индекс массива вычисляется по формуле `A.first + A.length - 1`

## Порядок следования

Если два значения сравнимы (например, оба значения числовые), то определены следующие
порядки следования элементов друг за другом:

- **Возрастающий порядок**: элементы `x` и `y` связаны отношением частичного порядка `<`
    - Элемент `x` _предшествует_ элементу `y` (`y` _следует за_ `x`), если `x < y`
- **Убывающий порядок**: элементы `x` и `y` связаны отношением частичного порядка `>`
    - Элемент `x` _предшествует_ элементу `y` (`y` _следует за_ `x`), если `x > y`
- **Неубывающий порядок**: элементы `x` и `y` связаны отношением частичного порядка `<=`
    - Элемент `x` _предшествует_ элементу `y` (`y` _следует за_ `x`), если `x <= y`
- **Невозрастающий порядок**: элементы `x` и `y` связаны отношением частичного порядка `>=`
    - Элемент `x` _предшествует_ элементу `y` (`y` _следует за_ `x`), если `x >= y`

Для определения порядка следования элементов применяется процедура `compare`:
```
compare(x, y)
    Вход:
        x, y: сравниваемые значения
    Выход:
        -1: если значение x предшествует значению y
         0: если значения x и y равны
         1: если значение x следует за значением y

    if x == y
        return 0
    elseif x предшествует y
        return -1
    else
        return 1
```
