# Поиск

Постановка **задачи поиска**:

> **Вход**: Последовательность из _n_ чисел _A = &lt;a1, a2, ..., an&gt;_ и значение _v_.  
> **Выход**: Индекс _i_ такой, что _v = A[i]_, или специальное значение _NIL_, если _v_ в _A_ отсутствует.

## Линейный поиск

### Простой линейный поиск

```
linear-search(A, p, r, x)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
        x: искомое значение
    Выход:
        индекс элемента или NIL

    for i := p to r
        if A[i] == x
            return i            // вернуть индекс
    return NIL                  // искомое значение не найдено
```

### Линейный поиск с ограничителем

```
sentinel-linear-search(A, p, r, x)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
        x: искомое значение
    Выход:
        индекс элемента или NIL

    if p > r                    // подмассив пуст
        return NIL
    last := A[r]                // сохранить последний элемент
    A[r] := x                   // использовать значение x в качестве ограничителя
    i := p                      // начальный индекс массива
    while A[i] != x
        i := i + 1
    A[r] = last                 // восстановить последний элемент
    if i < r или A[r] == x
        return i                // вернуть индекс
    return NIL                  // искомое значение не найдено
```

### Рекурсивный линейный поиск

```
recursive-linear-search(A, p, r, x)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
        x: искомое значение
    Выход:
        индекс элемента или NIL

    if p > r                // подмассив пуст
        return NIL          // искомое значение не найдено
    if A[p] == x
        return p            // вернуть индекс
    return recursive-linear-search(A, p + 1, r, x)   // вернуть результат рекурсивного вызова
```

## Бинарный поиск

### Простой бинарный поиск

```
binary-search(A, p, r, x)
    Вход:
        A: отсортированный массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
        x: искомое значение
    Выход:
        индекс элемента или NIL

    while p <= r
        q := (p + r) / 2    // средний индекс подмассива (целочисленное деление)
        if A[q] == x
            return q        // вернуть индекс
        if A[q] > x
            r := q - 1      // изменить конечный индекс подмассива
        else
            p := q + 1      // изменить начальный индекс подмассива
    return NIL              // искомое значение не найдено
```

### Рекурсивный бинарный поиск

```
recursive-binary-search(A, p, r, x)
    Вход:
        A: отсортированный массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
        x: искомое значение
    Выход:
        индекс элемента или NIL

    if p > r
        return NIL          // искомое значение не найдено
    q := (p + r) / 2        // средний индекс подмассива (целочисленное деление)
    if A[q] == x
        return q            // вернуть индекс
    if A[q] > x
        return recursive-binary-search(A, p, q - 1, x)
    else
        return recursive-binary-search(A, q + 1, r, x)
```

## Медианы и порядковые статистики

Постановка **задачи выбора**:

> **Вход**: Множество _A_, состоящее из _n_ (различных) чисел, и число _1 &le; i &le; n_.  
> **Выход**: Элемент _x &isin; A_, превышающий по величине ровно _i - 1_ других элементов множества _A_.

### Минимум и максимум

```
minimum(A, p, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
    Выход:
        минимальное значение

    min := A[p]
    for i := p + 1 to r
        if min > A[i]
            min := A[i]
    return min
```
```
maximum(A, p, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
    Выход:
        максимальное значение

    max := A[p]
    for i := p + 1 to r
        if max < A[i]
            max := A[i]
    return max
```
```
minmax(A, p, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
    Выход:
        кортеж, содержащий минимальное и максимальное значения

    n := r - p + 1              // количество элементов в подмассиве A[p..r]
    b := p + 1                  // установить начальный индекс цикла
    if n mod 2 == 0
        // если количество элементов подмассива A[p..r] чётное,
        // определить, какой из первых двух элементов подмассива
        // будет взят за основу для минимума, а какой для максимума
        if A[p] < A[p + 1]
            imin := p
            imax := p + 1
        else
            imin := p + 1
            imax := p
        b := b + 1              // обновить начальный индекс цикла (p + 2)
    else
        // если количество элементов подмассива A[p..r] нечётное,
        // за основу минимума и максимума берётся первый элемент
        imin := imax := p
    min := A[imin]
    max := A[imax]

    for i := b to r - 1 by 2    // цикл с шагом 2
        // определить, какой из очередных двух элементов подмассива
        // будет сравниваться с минимумом, а какой с максимумом
        if A[i] < A[i + 1]
            imin := i
            imax := i + 1
        else
            imin := i + 1
            imax := i
        if min > A[imin]
            min := A[imin]
        if max < A[imax]
            max := A[imax]

    return (min, max)
```

### Выбор порядковой статистики

```
randomized-select(A, p, r, i)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
        i: порядковый номер элемента подмассива A[p..r]
    Выход:
        значение i-ой порядковой статистики

    if p == r           // базовый случай рекурсии - единственный элемент
        return A[p]
    q := randomized-partition(A, p, r)
    k := q - p + 1      // количество элементов в левом подмассиве A[p..q]
    if i == k           // опорный элемент является искомым
        return A[q]
    elseif i < k
        return randomized-select(A, p, q - 1, i)
    else
        return randomized-select(A, q + 1, r, i - k)
```
