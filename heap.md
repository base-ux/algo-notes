# Бинарная пирамида

Бинарная пирамида является бинарным деревом и обладает следующим свойством:

- неубывающая пирамида: ключи потомков больше или равны ключу родителя
- невозрастающая пирамида: ключи потомков меньше или равны ключу родителя

Вместо связей (указателей или ссылок) между узлами (родитель, левый потомок,
правый потомок) лучше реализовать её в виде массива.
В псевдокоде процедур используются следующие атрибуты массива пирамиды:
```
H.first: начальный индекс массива пирамиды
H.last: индекс текущего конечного элемента пирамиды
H.size: предельный размер массива пирамиды
```
Индексы узлов находятся по следующим формулам:

- `left := 2 * i - H.first + 1` для левого потомка
- `right := 2 * i - H.first + 2` для правого потомка (или `left + 1`)
- `parent := (i + H.first - 1) / 2` для родителя (целочисленное деление)

В частности, при индексации массива с 0:

- `left := 2 * i + 1` для левого потомка
- `right := 2 * i + 2` для правого потомка
- `parent := (i - 1) / 2` для родителя (целочисленное деление)

При индексации массива с 1:

- `left := 2 * i` для левого потомка
- `right := 2 * i + 1` для правого потомка
- `parent := i / 2` для родителя (целочисленное деление)

## Операции

- Нахождение индекса родителя (parent)
- Нахождение индекса левого потомка (left)
- Нахождение индекса правого потомка (right)
- Вставка нового элемента (insert)
- Просмотр эктремального элемента (peak)
- Извлечение экстремального элемента (extract)
- Смещение элемента вверх (shift-up)
- Смещение элемента вниз (shift-down)
- Изменение ключа элемента (change-key)
- Создание пирамиды из массива (heapify)
- Пирамидальная сортировка (heap-sort)

В псевдокоде применяется процедура `compare` для определения порядка
следования элементов: порядок следования в пирамиде нарушается в случае,
если потомок предшествует родителю `compare(parent, child) > 0`.

### Нахождение индекса родителя (parent)

```
parent(i)
    Вход:
        i: индекс элемента
    Выход:
        индекс родительского элемента

    return (i + H.first - 1) / 2    // целочисленное деление
```

### Нахождение индекса левого потомка (left)

```
left(i)
    Вход:
        i: индекс элемента
    Выход:
        индекс левого потомка

    return 2 * i - H.first + 1
```

### Нахождение индекса правого потомка (right)

```
right(i)
    Вход:
        i: индекс элемента
    Выход:
        индекс правого потомка

    return left(i) + 1
```

### Вставка нового элемента (insert)

```
insert(A, x)
    Вход:
        A: массив пирамиды
        x: новый элемент

    if H.last >= H.first + H.size
        error "Пирамида полна"
    H.last := H.last + 1            // увеличить размер пирамиды
    A[H.last] := x                  // вставить новый элемент в конец пирамиды
    shift-up(A, H.last)             // сместить новый элемент вверх
```

### Просмотр эктремального элемента (peak)

```
peak(A)
    Вход:
        A: массив пирамиды
    Выход:
        экстремальный (верхний) элемент пирамиды

    if H.last < H.first
        error "Пирамида пуста"
    return A[H.first]
```

### Извлечение экстремального элемента (extract)

```
extract(A)
    Вход:
        A: массив пирамиды
    Выход:
        экстремальный (верхний) элемент пирамиды

    if H.last < H.first
        error "Пирамида пуста"
    x := A[H.first]                 // сохранить экстремальный элемент
    A[H.first] := A[H.last]         // переместить последний элемент пирамиды в корневой
    H.last := H.last - 1            // уменьшить размер пирамиды
    shift-down(A, H.first)          // сместить корневой элемент вниз
    return x                        // вернуть экстремальный элемент
```

### Смещение элемента вверх (shift-up)

```
shift-up(A, i)
    Вход:
        A: массив пирамиды
        i: индекс элемента

    if i > H.first                          // не корневой элемент
        p := parent(i)                      // индекс родителя
        if compare(A[p], A[i]) > 0          // если порядок пирамиды нарушен
            обменять элементы A[p] и A[i]
            shift-up(A, p)                  // повторить процедуру смещения для родителя
```

### Смещение элемента вниз (shift-down)

```
shift-down(A, i)
    Вход:
        A: массив пирамиды
        i: индекс элемента

    l := left(i)                // индекс левого потомка
    r := right(i)               // индекс правого потомка
    m := i                      // положить элемент A[i] экстремальным
    // если левый потомок существует и предшествует родителю
    if l <= H.last и compare(A[l], A[i]) < 0
        m := l                  // обновить индекс экстремального элемента
    // если правый потомок существует и предшествует элементу A[m]
    if r <= H.last и compare(A[r], A[m]) < 0
        m := r                  // обновить индекс экстремального элемента
    if m != i
        обменять A[i] и A[m]
        shift-down(A, m)        // повторить процедуру смещения для потомка
```

### Изменение ключа элемента (change-key)

```
change-key(A, i, k)
    Вход:
        A: массив пирамиды
        i: индекс элемента
        k: новый ключ элемента

    p := parent(i)                  // индекс родителя
    A[i] := k                       // установить новое значение ключа
    if compare(A[p], k) > 0         // если порядок пирамиды нарушен
        shift-up(A, i)
    else
        shift-down(A, i)
```

### Создание пирамиды из массива (heapify)

```
heapify(A, p, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
    Выход:
        подмассив A[p..r], преобразованный в пирамиду

    // если p >= r, то подмассив или пуст, или содержит единственный элемент
    // в этом случае никаких действий не требуется
    if p < r
        // установить атрибуты для пирамиды
        H.first := p
        H.last := r
        H.size := r - p + 1
        // начать с крайнего правого узла с потомком и до корневого узла
        for i := parent(H.last) downto H.first
            shift-down(A, i)    // сместить элемент вниз
```

### Пирамидальная сортировка (heap-sort)

```
heap-sort(A, p, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
    Выход:
        отсортированный подмассив A[p..r]

    heapify(A, p, r)     // преобразовать массив в пирамиду
    // от последнего элемента пирамиды и до первого потомка корневого узла
    for i := r downto p + 1
        x := extract(A)  // получить экстремальный элемент
        A[i] := x        // вставить его в конец подмассива
```
