# Бинарное дерево поиска (BST)

Бинарное дерево - структура данных корневого дерева, в которой каждый узел
имеет не более двух потомков, именуемых левым (left) и правым (right) потомками.
Бинарное дерево поиска обладает следующим свойством:

Пусть _x_ представляет собой узел бинарного дерева поиска.
Если _y_ является узлом в левом поддереве _x_, то _y_ предшествует _x_
(иными словами ключ _y.key &le; x.key_).
Если _y_ является узлом в правом поддереве _x_, то _y_ следует за _x_
(иными словами ключ _y.key &ge; x.key_).

В псевдокоде процедур используются следующие атрибуты бинарного дерева поиска:
```
T.root: указатель на корневой узел дерева
```
Каждый узел дерева имеет следующие атрибуты:
```
e.obj: указатель на объект, хранящий данные (ключ и сопутствующие данные)
e.left: указатель на корневой узел левого поддерева (левый потомок)
e.right: указатель на корневой узел правого поддерева (правый потомок)
```
Дополнительно узел может содержать следующий атрибут:
```
e.parent: указатель на родительский узел
```
Если `T.root` имеет значение `NIL`, то дерево пустое.
Если `e.left` (`e.right`) имеет значение `NIL`, то левое (правое) поддерево пустое.
Если используется атрибут `e.parent`, и он имеет значение `NIL`, то узел
является корневым.
Атрибут `e.obj` либо представляет собой непосредственные данные (например,
числовое значение), либо указатель на структуру, содержащую данные.
Для сравнения значения узлов (ключей) применяется процедура `compare`.

## Операции

- Вставка (insert)
- Поиск (search)
- Поиск минимального элемента (minimum)
- Поиск максимального элемента (maximum)
- Поиск предшественника (predecessor)
- Поиск последователя (successor)
- Удаление (delete)
- Симметричный обход дерева (in-order)
- Прямой обход дерева (pre-order)
- Обратный обход дерева (post-order)

### Поиск родительского узла (вспомогательная процедура)

В случае, если атрибут `e.parent` не применяется, осуществляется поиск родительского
узла, начиная с корневого узла:
```
parent(T, x)
    Вход:
        T: указатель на структуру дерева
        x: указатель на узел, для которого ищется родительский
    Выход:
        указатель на родительский узел или NIL

    p := NIL                    // указатель на родительский узел
    c := T.root                 // указатель на текущий узел
    while c != NIL и c != x
        p := c
        if compare(x.obj, c.obj) < 0    // x предшествует c?
            c := c.left
        else
            c := c.right
    if c == NIL
        return NIL              // узел не найден
    else
        return p
```
В случае, если атрибут `e.parent` применяется, то просто возвращается его значение:
```
parent(T, x)
    Вход:
        T: указатель на структуру дерева
        x: указатель на узел, для которого ищется родительский
    Выход:
        указатель на родительский узел или NIL

    return x.parent
```

### Вставка (insert)

```
insert(T, x)
    Вход:
        T: указатель на структуру дерева
        x: новый узел

    p := NIL                            // указатель на родительский узел
    c := T.root                         // указатель на текущий узел
    while c != NIL
        p := c
        if compare(x.obj, c.obj) < 0    // x предшествует c?
            c := c.left
        else
            c := c.right
    if p == NIL
        T.root := x                     // дерево T было пустым
    elseif compare(x.obj, p.obj) < 0    // x предшествует p?
        p.left := x
    else
        p.right := x
    // если применяется атрибут e.parent, то установить его у узла x
    x.parent := p
```

### Поиск (search)

```
search(T, k)
    Вход:
        T: указатель на структуру дерева
        k: объект, содержащий искомый ключ
    Выход:
        указатель на найденный узел или NIL

    c := T.root
    while c != NIL и compare(k, c.obj) != 0
        if compare(k, c.obj) < 0    // k предшествует c?
            c := c.left
        else
            c := c.right
    return c
```

### Поиск минимального элемента (minimum)

Для поиска минимального элемента во всём дереве вызов выглядит как `minimum(T.root)`.

```
minimum(t)
    Вход:
        t: указатель на корневой узел поддерева
    Выход:
        указатель на найденный узел или NIL

    if t != NIL
        while t.left != NIL
            t := t.left
    return t
```

### Поиск максимального элемента (maximum)

Для поиска максимального элемента во всём дереве вызов выглядит как `minimum(T.root)`.

```
maximum(t)
    Вход:
        t: указатель на корневой узел поддерева
    Выход:
        указатель на найденный узел или NIL

    if t != NIL
        while t.right != NIL
            t := t.right
    return t
```

### Поиск предшественника (predecessor)

```
predecessor(T, x)
    Вход:
        T: указатель на структуру дерева
        x: указатель на узел, для которого осуществляется поиск предшественника
    Выход:
        указатель на найденный узел или NIL

    // если существует левый потомок узла, то предшественником является
    // максимальный узел этого потомка
    if x != NIL и x.left != NIL
        return maximum(x.left)
    // иначе найти такого предка, для которого данный узел является последователем
    p := parent(T, x)
    while p != NIL и x == p.left
        x := p
        p := parent(T, p)
    return p
```

### Поиск последователя (successor)

```
successor(T, x)
    Вход:
        T: указатель на структуру дерева
        x: указатель на узел, для которого осуществляется поиск последователя
    Выход:
        указатель на найденный узел или NIL

    // если существует правый потомок узла, то последователем является
    // минимальный узел этого потомка
    if x != NIL и x.right != NIL
        return minimum(x.right)
    // иначе найти такого предка, для которого данный узел является предшественником
    p := parent(T, x)
    while p != NIL и x == p.right
        x := p
        p := parent(T, p)
    return p
```

### Удаление (delete)

В процедуре `delete` применяется вспомогательная процедура `transplant`, которая
заменяет одно поддерево другим.

```
delete(T, k)
    Вход:
        T: указатель на структуру дерева
        k: объект, содержащий искомый ключ

    d := search(T, k)                   // поиск удаляемого узла
    if d != NIL
        if d.left == NIL                // у удаляемого узла нет левого потомка
            transplant(T, d, d.right)   // заменить удаляемый узел на правое поддерево
        elseif d.right == NIL           // у удаляемого узла нет правого потомка
            transplant(T, d, d.left)    // заменить удаляемый узел на левое поддерево
        else                            // у удаляемого узла есть оба потомка
            m := minimum(d.right)       // поиск последователя удаляемого узла
            if parent(T, m) != d
                // заменить последователя его правым поддеревом,
                // а его правое поддерево заменить правым поддеревом удаляемого узла
                transplant(T, m, m.right)
                m.right := d.right
                // если используется атрибут e.parent, то обновить его у узла m.right
                m.right.parent := m
            // заменить удаляемый узел последователем,
            // а левое поддерево удаляемого узла подцепить к последователю
            transplant(T, d, m)
            m.left := d.left
            // если используется атрибут e.parent, то обновить его у узла m.left
            m.left.parent := m
```
```
transplant(T, u, v)
    Вход:
        T: указатель на структуру дерева
        u: указатель на заменяемое поддерево
        v: указатель на заменяющее поддерево

    p := parent(T, u)
    if p == NIL
        T.root := v
    elseif u == p.left
        p.left := v
    else
        p.right := v
    // если используется атрибут e.parent, то обновить его у узла v
    if v != NIL
        v.parent := p
```

### Симметричный обход дерева (in-order)

Для симметричного обхода всего дерева вызов выглядит как `in-order(T.root)`.

#### Итеративный вариант

```
in-order(t)
    Вход:
        t: указатель на корневой узел поддерева

    Пусть S - новый стек
    while stack-empty(S) == FALSE или t != NIL
        if t != NIL
            stack-push(S, t)
            t := t.left
        else
            t := stack-pop(S)
            выполнение какой-либо операции с текущим узлом t
            t := t.right
```

#### Рекурсивный вариант

```
in-order(t)
    Вход:
        t: указатель на корневой узел поддерева

    if t != NIL
        in-order(t.left)
        выполнение какой-либо операции с текущим узлом t
        in-order(t.right)
```

### Прямой обход дерева (pre-order)

Для прямого обхода всего дерева вызов выглядит как `pre-order(T.root)`.

#### Итеративный вариант

```
pre-order(t)
    Вход:
        t: указатель на корневой узел поддерева

    if t != NIL
        Пусть S - новый стек
        stack-push(S, t)
        while stack-empty(S) == FALSE
            t := stack-pop(S)
            выполнение какой-либо операции с текущим узлом t
            if t.right != NIL
                stack-push(S, t.right)
            if t.left != NIL
                stack-push(S, t.left)
```

#### Рекурсивный вариант

```
pre-order(t)
    Вход:
        t: указатель на корневой узел поддерева

    if t != NIL
        выполнение какой-либо операции с текущим узлом t
        pre-order(t.left)
        pre-order(t.right)
```

### Обратный обход дерева (post-order)

Для обратного обхода всего дерева вызов выглядит как `post-order(T.root)`.

#### Итеративный вариант

```
post-order(t)
    Вход:
        t: указатель на корневой узел поддерева

    Пусть S - новый стек
    last := NIL
    while stack-empty(S) == FALSE или t != NIL
        if t != NIL
            stack-push(S, t)
            t := t.left
        else
            peek := stack-peek(S)
            if peek.right != NIL и last != peek.right
                t := peek.right
            else
                выполнение какой-либо операции с узлом peek
                last := stack-pop(S)
```

#### Рекурсивный вариант

```
post-order(t)
    Вход:
        t: указатель на корневой узел поддерева

    if t != NIL
        post-order(t.left)
        post-order(t.right)
        выполнение какой-либо операции с текущим узлом t
```
