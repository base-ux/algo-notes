# Сортировка

Постановка **задачи сортировки**:

> **Вход**: Последовательность из _n_ чисел _&lt;a1, a2, ..., an&gt;_.  
> **Выход**: Перестановка (переупорядочение) _&lt;a1', a2', ..., an'&gt;_ входной последовательности,
> такая, что _a1' &le; a2' &le; ... &le; an'_.

В процедурах в качестве параметров указываются начальный индекс `p` и конечный индекс `r`
подмассива `A[p..r]`.
Это позволяет сортировать только подмассив исходного массива.
Для сортировки массива целиком используются вызовы:

- `sort(A, 0, A.length-1)`, если индексация массива начинается с `0`
- `sort(A, 1, A.length)`, если индексация массива начинается с `1`

В процедурах сортировки применяется процедура `compare` для определения порядка
следования элементов массива.

## Сортировка вставкой

```
insertion-sort(A, p, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
    Выход:
        отсортированный подмассив A[p..r]

    // если p >= r, то подмассив или пуст, или содержит единственный элемент
    // в этом случае никаких действий не требуется
    if p < r
        for j := p + 1 to r
            key := A[j]         // запомнить элемент
            // т.к. подмассив A[p..j-1] уже отсортирован,
            // соответственно, осуществить поиск подходящего места
            // для вставки сохранённого элемента, смещая элементы к концу подмассива
            i := j - 1
            while i >= p и compare(key, A[i]) < 0   // key предшествует A[i]
                A[i + 1] := A[i]
                i := i - 1
            A[i + 1] := key     // вставить запомненный элемент
```

## Сортировка выбором

```
selection-sort(A, p, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
    Выход:
        отсортированный подмассив A[p..r]

    // если p >= r, то подмассив или пуст, или содержит единственный элемент
    // в этом случае никаких действий не требуется
    if p < r
        for i := p to r - 1         // до предпоследнего элемента
            m := i                  // запомнить индекс мин. (макс.) элемента
            for j := i + 1 to r
                if compare(A[j], A[m]) < 0  // A[j] предшествует A[m]
                    m := j          // обновить индекс мин. (макс.) элемента
            обменять A[i] и A[m]
```

## Пузырьковая сортировка

```
bubble-sort(A, p, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
    Выход:
        отсортированный подмассив A[p..r]

    // если p >= r, то подмассив или пуст, или содержит единственный элемент
    // в этом случае никаких действий не требуется
    if p < r
        for i := p to r - 1             // до предпоследнего элемента
            for j := r downto i + 1
                if compare(A[j], A[j - 1]) < 0  // A[j] предшествует A[j - 1]
                    обменять A[j] и A[j - 1]
```

## Сортировка слиянием

```
merge(A, p, q, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        q: средний индекс подмассива A[p..r] (p <= q <= r)
        r: конечный индекс подмассива A[p..r]
    Выход:
        подмассив A[p..r], слитый из подмассивов A[p..q] и A[q+1..r]

    n1 := q - p + 1             // количество элементов в подмассиве A[p..q]
    n2 := r - q                 // количество элементов в подмассиве A[q+1..r]
    Пусть L[1..n1] и R[1..n2] - новые массивы
    // скопировать соответствующие подмассивы в массивы L и R
    for i := 1 to n1
        L[i] := A[p + i - 1]
    for j := 1 to n2
        R[j] := A[q + j]
    // установить текущие индексы массивов A, L и R
    k := p
    i := 1
    j := 1
    // скопировать элементы из массивов L и R обратно в подмассив A[p..r]
    while i <= n1 и j <= n2             // пока оба подмассива содержат элементы
        if compare(L[i], R[j]) <= 0     // элемент L[i] предшествует или равен R[j]
            A[k] := L[i]
            i := i + 1
        else
            A[k] := R[j]
            j := j + 1
        k := k + 1
    // один из подмассивов закончился - скопировать оставшиеся элементы из второго
    while k <= r
        if i <= n1              // закончился правый подмассив?
            A[k] := L[i]
            i := i + 1
        else
            A[k] := R[j]
            j := j + 1
        k := k + 1
```
```
merge-sort(A, p, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
    Выход:
        отсортированный подмассив A[p..r]

    // если p >= r, то подмассив или пуст, или содержит единственный элемент
    // в этом случае никаких действий не требуется
    if p < r
        q := (p + r) / 2            // средний индекс подмассива (целочисленное деление)
        merge-sort(A, p, q)         // сортировка левого подмассива A[p..q]
        merge-sort(A, q + 1, r)     // сортировка правого подмассива A[q+1..r]
        merge(A, p, q, r)           // слияние отсортированных подмассивов
```

## Быстрая сортировка

```
partition(A, p, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
    Выход:
        индекс опорного элемента q такого, что
          - все элементы подмассива A[p..q-1] меньше или равны A[q]
          - все элементы подмассива A[q+1..r] больше A[q]

    x := A[r]                       // опорный элемент
    i := p - 1
    for j := p to r - 1             // до предпоследнего элемента (последний - опорный)
        if compare(A[j], x) <= 0    // элемент A[j] предшествует или равен опорному
            i := i + 1
            if i != j               // менять только различные элементы
                обменять A[i] и A[j]
    обменять A[i + 1] и A[r]        // поместить опорный элемент в нужную позицию
    return i + 1                    // вернуть индекс опорного элемента
```
```
randomized-partition(A, p, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
    Выход:
        индекс опорного элемента q такого, что
          - все элементы подмассива A[p..q-1] меньше или равны A[q]
          - все элементы подмассива A[q+1..r] больше A[q]

    i := random(p, r)       // выбрать случайный индекс в диапазоне [p..r]
    обменять A[r] и A[i]
    return partition(A, p, r)
```
```
quick-sort(A, p, r)
    Вход:
        A: массив
        p: начальный индекс подмассива A[p..r]
        r: конечный индекс подмассива A[p..r]
    Выход:
        отсортированный подмассив A[p..r]

    // если p >= r, то подмассив или пуст, или содержит единственный элемент
    // в этом случае никаких действий не требуется
    if p < r
        // для рандомизированного алгоритма заменить вызов
        // partition на randomized-partition
        q := partition(A, p, r)     // разбить массив и получить индекс опорного элемента
        quick-sort(A, p, q - 1)     // сортировка левого подмассива A[p..q-1]
        quick-sort(A, q + 1, r)     // сортировка правого подмассива A[q+1..r]
```

## Сортировка подсчётом

В сортировке подсчётом предполагается, что каждый из `n` входных элементов - целое число,
принадлежащее интервалу `0 .. k`, где `k` - некоторая целая константа.

Основная идея сортировки подсчётом заключается в том, чтобы для каждого входного элемента `x`
определить количество элементов, которые меньше `x`.
С помощью этой информации элемент `x` можно разместить в той позиции выходного массива,
где он должен находиться.

```
counting-sort(A, B, p, r, k)
    Вход:
        A: исходный массив
        B: целевой массив, в который помещаются отсортированные элементы
        p: начальный индекс подмассивов A[p..r], B[p..r]
        r: конечный индекс подмассивов A[p..r], B[p..r]
        k: верхняя граница интервала 0..k допустимых значений ключа
    Выход:
        отсортированный подмассив B[p..r]

    Пусть C[0..k] - новый массив
    // инициализировать массив C нулевыми значениями
    for i := 0 to k
        C[i] := 0
    // подсчитать количество элементов, равных j
    for j := p to r
        C[A[j]] := C[A[j]] + 1
    // подсчитать количество элементов, не превышающих i
    for i := 1 to k
        C[i] := C[i] + C[i - 1]
    // заполнить массив B отсортированными данными
    //   в данной реализации алгоритм обладает свойством устойчивости, т.е.
    //   элементы с одним и тем же значением находятся в выходном массиве
    //   в том же порядке, что и во входном (важно, если есть сопутствующие
    //   данные); при цикле p to r порядок будет обратным
    for j := r downto p
        q := p + C[A[j]] - 1    // вычисление надлежащей позиции в целевом массиве
        B[q] := A[j]
        C[A[j]] := C[A[j]] - 1
```

## Поразрядная сортировка

При поразрядной сортировке сначала производится сортировка по младшей цифре (символу),
затем по предпоследней цифре (символу) и т.д. по всем `d` цифрам (символам).

```
radix-sort(A, d)
    Вход:
        A: массив
        d: количество цифр (символов) в элементе данных
    Выход:
        отсортированный массив A

    for i := d downto 1
        Выполнить устойчивую сортировку массива A по цифре (символу) i
```
