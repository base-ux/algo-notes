# Очередь

Структура данных, реализующая стратегию "первый вошёл - первый вышел"
(first-in, first-out - FIFO).
Реализуется на базе массивов или связных списков.
Далее показаны процедуры реализации очереди на базе массива.
В псевдокоде процедур используются следующие атрибуты массива очереди:
```
Q.head: индекс головы очереди
Q.tail: индекс хвоста очереди
Q.first: начальный индекс массива очереди
Q.last: конечный индекс массива очереди
```
Очередь циклически замкнута, т.е. после элемента `Q.last` следует элемент `Q.head`.
Индекс `Q.head` указывает на головной элемент очереди, индекс `Q.tail` - на
местоположение, куда будет вставляться новый элемент.

## Операции

- Инициализация очереди (initialize)
- Проверка на наличие элементов (empty)
- Проверка на переполнение (full)
- Вставка элемента (enqueue)
- Извлечение элемента (dequeue)

### Инициализация очереди (initialize)

```
initialize(Q, p, r)
    Вход:
        Q: массив очереди
        p: начальный индекс подмассива Q[p..r]
        r: конечный индекс подмассива Q[p..r]

    if p > r
        error "Ошибка инициализации"
    Q.first := p
    Q.last := r
    Q.head := Q.tail := Q.first
```

### Проверка на наличие элементов (empty)

```
empty(Q)
    Вход:
        Q: массив очереди
    Выход:
        TRUE: если очередь не содержит элементов
        FALSE: в противном случае

    if Q.head == Q.tail
        return TRUE
    else
        return FALSE
```

### Проверка на переполнение (full)

```
full(Q)
    Вход:
        Q: массив очереди
    Выход:
        TRUE: если очередь переполнена
        FALSE: в противном случае

    if (Q.head == Q.tail + 1) или (Q.head == Q.first и Q.tail == Q.last)
        return TRUE
    else
        return FALSE
```

### Вставка элемента (enqueue)

```
enqueue(Q, x)
    Вход:
        Q: массив очереди
        x: добавляемый элемент

    if full(Q)
        error "overflow: переполнение очереди"
    Q[Q.tail] := x
    if Q.tail == Q.last
        Q.tail := Q.first
    else
        Q.tail := Q.tail + 1
```

### Извлечение элемента (dequeue)

```
dequeue(S)
    Вход:
        Q: массив очереди
    Выход:
        извлекаемый элемент

    if empty(Q)
        error "underflow: опустошение очереди"
    x := Q[Q.head]
    if Q.head == Q.last
        Q.head := Q.first
    else
        Q.head := Q.head + 1
    return x
```
